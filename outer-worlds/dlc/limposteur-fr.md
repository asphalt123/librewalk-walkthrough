
## Les armes du Grand Vide

- **Objectif** : Obtenir les armes du Grand Vide.  
- **Étape 1** : Explorer les zones indiquées dans la quête secondaire.  
- **Étape 2** : Trouver les points d'intérêt marqués sur la carte.  
- **Étape 3** : Vaincre les ennemis gardant les armes.  
- **Étape 4** : Récupérer les armes et les ajouter à votre inventaire.  
- **Conseil** : Utilisez **l'arme de préférence** pour faciliter les combats contre les ennemis de haut niveau.
