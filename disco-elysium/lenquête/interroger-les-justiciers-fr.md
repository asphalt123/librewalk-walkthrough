# Interroger les justiciers

## 1. Préparer l’enquête

1. Le matin du deuxième jour (Mardi), parlez à **Kim** dans le hall du Whirling pour obtenir des informations sur les membres du syndicat occupant le box et terminer la tâche **« Découvrir qui est dans le box du syndicat »**.  
2. Approchez le box et engagez la conversation avec **Elizabeth la Jardinière** (avocate des Hardie Boys).  

## 2. Analyser les traces de pas

1. Avant de parler à **Titus**, rendez‑vous sur la scène de crime.  
2. Effectuez un jet de **Projection analytique (Intermédiaire 11)** sur les traces de pas.  
   - En cas de succès, vous analysez les empreintes et récupérez des informations utiles pour l’interrogatoire.  

## 3. Interroger Titus

1. Approchez **Titus** et commencez par observer la pièce : examinez les membres de la bande et comparez leurs morphologies aux traces de pas relevées.  
2. Lancez le véritable interrogatoire en abordant les sujets suivants (vous pouvez les évoquer dans l’ordre qui vous convient) :
   - Les traces de pas sur le sol et l’absence du **8ᵉ Hardie**.  
   - Le corps trouvé dans la cour et la sangle de docker autour du cou.  
   - La personne qui donnait les ordres la nuit du meurtre ; suggérez que le Hardie manquant pourrait être le vrai chef.  
   - Les raisons du meurtre, révélant l’existence d’une jeune femme agressée par la victime.  
   - Les circonstances de la mort : soulignez les incohérences dans le récit de **Titus**.  
   - La balle découverte dans la tête du mort ; insistez pour montrer que **Titus** ne peut expliquer ce projectile.  

3. Après avoir couvert ces points, vous pouvez tenter un jet de **Sang‑froid (Difficile 12)** pour identifier quel Hardie Boy pourrait craquer sous la pression.  

## 4. Conclusion de la tâche

- Une fois ces dialogues terminés, la tâche **« Interroger les justiciers »** se clôt.  
- Vous pouvez alors passer à l’étape suivante : **« Démontrer votre autorité à Titus Hardie »**.
